Self-healing for seven OCI Load Balancer backends

A private OCI Load Balancer routes internal HTTPS traffic to seven independently operated backend services. OCI Monitoring, Notifications, Functions, and instance pools detect, remove, terminate, and replace a persistently unhealthy VM while preserving each service’s configured capacity.

Default guardrail

Remediate one VM at a time per pool and no more than three VMs globally in 30 minutes. Pause during an active autoscaling operation.

Minimum healthy rule

The Function never acts if termination would take healthy capacity below the backend-specific approved threshold. A pool with one VM is alert-only.

Capacity strategy

Distribute instances across fault domains and reserve or pre-validate one replacement shape per pool. Exact placement and reservation values remain service-owner decisions.

Remediation transaction

Fail closed before deleting a VM

  1. Alarm FIRING
  2. Deduplicate + lock
  3. Re-read LB health
  4. Map exactly one pool member
  5. Check capacity + rate
  6. Detach + terminate
  7. Verify replacement healthy
  • Invoke the Compute Management detach operation with isAutoTerminate=true and isDecrementSize=false. The faulty VM is removed and desired pool size remains unchanged.
  • Delete the boot volume by setting preservation to false. Attached block volumes are also eligible for deletion because the owner approved this behavior, but only volumes explicitly created for that VM and tagged data-class=disposable are deleted. Shared or ambiguous attachments make remediation stop and email the owner.
  • Use one NoSQL lock and rolling replacement counter per pool. Duplicate ONS delivery must not produce a second termination.
  • Stop on multiple unhealthy members, ambiguous IP-to-instance mapping, a scaling pool, insufficient healthy capacity, missing metrics, or exhausted shape capacity.
  • Start with MODE=observe, then enable one non-production backend, then one production backend at a time.

Migration

Deploy the synthetic stack without a remediation storm

1. Validate the synthetic configuration

Confirm seven neutral service records, ports, capacity envelopes, health checks, replacement budgets, internal CIDR, email owner, repository, and CI/CD system.

2. Review one complete Terraform plan

Confirm the VCN, private LB, seven listeners/backend sets/pools/autoscaling policies, Functions, alarms, ONS, NoSQL, logging, IAM, and destroy boundary all belong to the synthetic state.

3. Apply in observe mode

Create the entire stack with every Function set to observe so alarms and mappings can be tested without terminating a VM.

4. Promote one synthetic service

Enable remediation only after all seven pools and backend sets are healthy and the email subscription is confirmed.

5. Deploy observe-only, then canary

Prove alarms, Function mapping, email, deduplication, and capacity decisions without mutation. Enable one backend at a time, inject an application-health failure, and confirm the pool returns to desired size with a healthy replacement inside the SLO.

Acceptance and rollback

What “working as intended” means

Acceptance tests

  • Each backend health failure affects only its own alarm and pool.
  • LB stops new traffic to the failed VM before termination.
  • Duplicate notifications cause one action.
  • Pool size is preserved and replacement becomes LB-healthy within 15 minutes.
  • Boot and eligible disposable block volumes are deleted.
  • Minimum healthy capacity, per-pool and global rate limits stop unsafe action.
  • Email records start, completion, blocked action, and SLO breach.
  • Terraform plan is clean after convergence.

Rollback / kill switch

  • Set Function MODE=observe to stop mutations immediately.
  • Disable the Function subscription while leaving email alarms active.
  • Restore the previous Function image digest and Terraform plan.
  • Do not reattach a known-faulty VM; restore desired capacity through the instance pool.
  • Use Terraform destroy only for resources owned by this component. Existing supplied resources remain untouched.
