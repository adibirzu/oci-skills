# Security policy

Report a suspected vulnerability privately to the repository maintainers through
the GitHub security-advisory reporting flow. Do not include credentials, OCIDs,
customer identifiers, private topology, or proof-of-concept payloads in a public
issue.

The report should contain a redacted impact description, affected revision,
reproduction prerequisites, and safe mitigation. Maintainers acknowledge the
report, assess scope, and coordinate a fix before public disclosure. This
community skill pack is not an Oracle support channel and does not grant access
to an OCI tenancy or authorization for security testing.

For an active customer or Oracle service incident, use the applicable official
Oracle support and incident process instead of this repository.
